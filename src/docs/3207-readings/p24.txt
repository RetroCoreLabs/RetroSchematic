note Write path (ND to SCSI): ENILA1~ latches the ND word SDIN00-15 in 15B (low byte) and 13E (high byte); ENILA2~ moves both into 14E and 11D, which put the low byte (SENDLO~) or the high byte (SENDHI~) on SMBD00-07.
note Read path (SCSI to ND): SLODLO~ / SLODHI~ latch an SMBD byte in 15E / 16E; ENOLA~ moves them into 13F / 17E, which drive SDOUT00-07 / SDOUT08-15 when SDOEN~ is low.
note The latch inputs are wired in reverse bit order on the drawing (SDIN07 on 1D ... SDIN00 on 8D, and 1Q -> SMBD07 ... 8Q -> SMBD00), so the bit numbers match end to end.
note OPEN: the 74F04 position is printed "1662" (checked at 1200 dpi). Read as 16G2 because G and 6 look the same in this font and a position code needs a letter; 16G itself is the 74S08 on sheet 9.
note Drawn by ASU (the other SCSI sheets: HS).
