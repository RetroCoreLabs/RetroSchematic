note 8B, 9B, 11A (74LS461 8-bit counters) hold the 24-bit DMA memory address: loaded from SDIN with DLMARL~ (8B, 9B: bits 0-15) and DLMARU~ (11A: bits 16-23, D from SDIN00-07), counted by SADCK, carry chained 8B -> 9B -> 11A. 11B (enable RMARU~) reads bits 16-23 back onto SDOUT00-07.
note 12F, 14F, 12E (74LS469 8-bit up/down counters, U/D tied high) are the 24-bit word count: loaded with LDWC~, clocked by CKWL/CKWM/CKWH, read with RWCL~ (12F and 14F, onto SDOUT00-15) and RWCH~ (12E, onto SDOUT00-07); the last borrow out 12E pin 14 is WCZ~ (word count zero). The first borrow in 12F pin 23 is 20B pin 11 = NOT NCR~ OR TEST.
note 12B (enable SRSTAT~) reads the status word as printed: SDOUT01 = GND (1A1 pin 2 drawn to ground), SDOUT04 = STRERR, SDOUT03 = SRFT, SDOUT02 = SRFT~, SDOUT00 = SENI, SDOUT05 = 19H Q, SDOUT06 = ESCSI~, SDOUT07 = PSING. 13B gives SDOUT08-15 = DRQ SINT SDACK STRERR BSYIN REQ ACK PDIFF.
note 28C is printed with input pin 3 and output pin 12 (checked at 800 dpi; the test key reads the same). Read as 13->12: sheet 23 uses 28C 3->4, 5->6, 1->2 and 9->8, so 13->12 is the only gate left on the 74F04 and the printed "3" is a drawing error for 13. CHECKED by elimination.
note 19H (74LS74): D tied to ground, clocked by SRSTAT~, set by RRST (through 18H), cleared at power-up through C30 and by TRST (through 18H): Q is a flag that reads 1 after a SCSI reset until the status word is read. INFERRED from the wiring.
note LDWC~ is printed with ~ here (and on sheet 15); sheet 19 prints it without at 13C pin 17.
