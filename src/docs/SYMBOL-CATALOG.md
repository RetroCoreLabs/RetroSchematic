# ND circuit diagram symbol catalogue

Every part in ND-13.003.01 "Circuit Diagram Symbols" (A/S Norsk Data-Elektronikk, July 1976), in the manual's order. Each entry shows the cut-out from the manual. Gate symbols also show the description used to recognise them on a drawing, the manual's formula, and the same gate drawn again in ND style and in modern style. Both drawings end their pin lines on the same points (checked by the unit test `GateShapeTests`).

This page is generated by `tools/build-catalog-page.py`. Do not edit it by hand.

128 parts, 31 of them gate symbols.

## How ND draws gates

| Kind | ND 1976 | Modern | How to recognise the ND symbol |
|---|---|---|---|
| NAND | ![nand in ND style](../catalog/symbols/nd1976/shapes/nand.png) | ![nand in modern style](../catalog/symbols/modern/shapes/nand.png) | Empty box |
| NOR | ![nor in ND style](../catalog/symbols/nd1976/shapes/nor.png) | ![nor in modern style](../catalog/symbols/modern/shapes/nor.png) | Box with an X |
| NOT | ![not in ND style](../catalog/symbols/nd1976/shapes/not.png) | ![not in modern style](../catalog/symbols/modern/shapes/not.png) | Box with a triangle inside |
| AND | ![and in ND style](../catalog/symbols/nd1976/shapes/and.png) | ![and in modern style](../catalog/symbols/modern/shapes/and.png) | Empty box followed by an inverter box |
| OR | ![or in ND style](../catalog/symbols/nd1976/shapes/or.png) | ![or in modern style](../catalog/symbols/modern/shapes/or.png) | X box followed by an inverter box |
| XOR | ![xor in ND style](../catalog/symbols/nd1976/shapes/xor.png) | ![xor in modern style](../catalog/symbols/modern/shapes/xor.png) | Box with the exclusive-OR mark |

Marks that change a symbol: a double vertical bar or a single diagonal at the output = open collector; a pointed right end = buffer/driver; edges running past the box = Schmitt trigger. Signal subscripts: 1 = active high, 0 = active low (manual page 2).
