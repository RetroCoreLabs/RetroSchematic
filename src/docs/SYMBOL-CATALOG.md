### 7413 - Dual 4-input NAND Schmitt trigger

- **Part:** 7413
- **Description:** Dual 4-input NAND Schmitt trigger
- **Formula:** Y = NOT(A AND B AND C AND D)
- **Manual page:** 7 (PDF page 13)

![7413 as drawn in ND-13.003.01](../catalog/symbols/nd1976/7413.png)

| ND 1976 | Modern |
|---|---|
| ![nand-schmitt4 in ND style](../catalog/symbols/nd1976/shapes/nand-schmitt4.png) | ![nand-schmitt4 in modern style](../catalog/symbols/modern/shapes/nand-schmitt4.png) |

- **Output:** totem-pole
- **What it looks like:** The empty NAND rectangle with four inputs; its top edge runs on to the right and its bottom edge runs on to the left. What a Schmitt trigger is: a normal TTL input switches at one voltage, so a slow or noisy signal near that voltage makes the output flicker between 0 and 1 several times. A Schmitt trigger input has two switching points instead: the input must rise above about 1.7 V before the output changes, and then fall below about 0.9 V before it changes back. The gap between them (the hysteresis) means noise and slow edges give one clean change. It is used on signals from cables, switches and RC delay circuits. The input still reads as plain logic 0 or 1; only its noise tolerance differs.
- **How to tell it apart:** Edges running past the box (top to the right, bottom to the left) = Schmitt trigger input.
